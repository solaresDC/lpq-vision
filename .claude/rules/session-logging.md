# Session Logging Rule
Count exchanges since the last saved session log. Warn me at 7, again at 12,
insistently at 15. When a meaningful task finishes (a file completed, a section
done, a bug fixed), prompt me to save. On `/log`, save immediately. Save to
`claude-autogenerated-docs/sessions/` as `YYYY-MM-DD-HHMM-<tema>.md` containing:
what was done, files touched, decisions made, open items, and the exact next step.
